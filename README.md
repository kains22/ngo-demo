# Demo NGO Website

## Project Overview
This is a demo website for an NGO. It showcases the organization’s mission, programs, gallery, and ways to donate or contact the team. The website is hosted live and fully responsive for all devices.

## Pages
- About Us
- Programs
- Education
- Gallery
- Donate
- Contact

## Features
- Buttons, forms, sliders
- Volunteer section
- Cards for programs and education
- Live video embedded
- Hover effects on buttons

## Tools / Technologies
- HTML
- CSS
- JavaScript

## Principles Applied
- Software Engineering basics (Module 1 of IBM Full-Stack JS Certificate)
- SDLC: Planning, Design, Implementation, Testing, Deployment
- Consistent layout, colors, and responsive design
- Documentation for portfolio
